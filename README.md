# Rede Simulada

## Descrição

Projeto académico desenvolvido em Python para estudar o roteamento em redes virtuais de computadores.

## Objetivo

Comparar uma estratégia de roteamento convencional com o algoritmo Q-Learning, uma técnica de aprendizado por reforço.

## Tecnologias

* Python

## Estrutura do projeto

Os ficheiros da simulação e as instruções de execução serão adicionados após a implementação e validação do código.

## Resultados

Os resultados serão documentados após a execução dos testes, de forma a permitir a sua verificação.

## Contexto académico

Trabalho sobre a aplicação do aprendizado por reforço na otimização do roteamento em redes de computadores.
